# 🏛️ أستوديو العمارة الذكي (MK ARCHVIZ AI Content Studio)

نظام أتمتة سحابي معماري مستقل 100%، يعمل 24/7 ومخصص للمهندسين المعماريين وطلبة العمارة في الجزائر والوطن العربي. يقوم بتتبع أحدث تريندات وأخبار العمارة العالمية والجزائرية، تحليل وتفكيك شرائح الكاروسيل المنافسة وإعادة بنائها شريحة بشريحة بمعايير هندسية احترافية، وتوليد خلفيات معمارية فاخرة دون وجوه بشرية، وإرسال الكاروسيل الكامل مع الكابشن المباشر إلى هاتفك عبر **Telegram**.

---

## 🌟 أبرز القدرات والمميزات الحديثة

1. **🔥 متتبع التريندات والأخبار المعمارية الموثوقة (`/trends`):**
   - يجلب مقالات ومشاريع حية وموثوقة من **ArchDaily**.
   - يدمج بنك موضوعات حيوية للواقع الجزائري (دفتر تربص الـ 18 شهراً CNOA، رخصة البناء والمرسوم 15-19، شقاء ليلة الـ Charrette وتسليم مشاريع EPAU/الجامعات، التحول نحو BIM/Revit، وأسرار مراقبة التسليح و CTC في الورشات).
   - إمكانية استعراض القائمة واختيار أي رقم (`1` إلى `6`) لتوليد كاروسيل هندسي متكامل عنها فوراً!

2. **🧠 محرك رؤية حاسوبية لنسخ الكاروسيل شريحة بشريحة (Multi-Slide Vision):**
   - قراءة كافة شرائح المنشور الأصلي والمخططات والرسومات اليدوية بالذكاء الاصطناعي الرؤيوي (**XKiro Qwen 3.8 Omni** مدعوماً بـ **GPT-4o-mini** و **Gemini**).
   - الحفاظ على نفس عدد وترتيب شرائح الكاروسيل (مثلاً: السنة الأولى ➔ السنة الثانية ➔ السنة الثالثة).

3. **🏛️ أسلوب وهوية معمارية جزائرية راقية (Senior Algerian Architect Persona):**
   - كتابة معمارية واقعية تبتعد كلياً عن الحشو الإنشائي الباهت.
   - استخدام دقيق للمصطلحات التقنية المتداولة في الجامعات والورشات ومكاتب الدراسات الجزائريين (*Atelier, Charrette, Rendu, Esquisse, Plan de masse, Coupe, Façade, CNOA, CTC, Carnet de stage, Ferraillage, BIM, Lumion, Corona*).

4. **🎨 توليد خلفيات معمارية نقية بدون وجوه (Pure Architecture Visuals):**
   - توليد صور فوتوغرافية معمارية 8K حصرية لكل موضوع عبر **CometAPI** (`gpt-image-2.5-flare`).
   - قواعد صارمة لمنع ظهور الوجوه البشرية أو الصور الشخصية (`pure architecture, no human faces, no portraits`).
   - بطاقات زجاجية فاخرة (Glassmorphism) مع التخلص من أي شريط مكرر في الأسفل.

5. **☁️ جاهز للتشغيل السحابي 24/7 على Render:**
   - مزود بخادم فحص صحي مدمج (`CloudHealthHandler`) على المنفذ `10000` ليظل نشطاً على مدار الساعة.
   - حاوية `Dockerfile` معتمدة مع حزم الخطوط العربية المدمجة.

## 📱 أوامر البوت عبر تيليغرام (`@archimouradbot`)

بمجرد تشغيل البوت أو استضافته، يمكنك التحكم به من هاتفك مباشرة:

| الأمر / الرسالة | الوظيفة |
| :--- | :--- |
| `/start` أو `/help` | عرض الدليل والتعليمات الشاملة للاستخدام |
| `/trends` أو `تريند` أو `أخبار` | جلب أحدث الموضوعات والتريندات المعمارية العالمية والجزائرية |
| `1` أو `2` أو `توليد 1` | توليد كاروسيل فوري متكامل للموضوع المختار من قائمة التريندات |
| `/generate` أو `توليد` | توليد تصميم فيلا/مشروع من الصفر مع لوحة المفاهيم والبرومبت |
| رابط إنستغرام (`https://...`) | تفكيك المنشور واستخراج شرائحه وتطويرها بهوية MK ARCHVIZ |
| أي نص أو فكرة | صياغة كاروسيل هندسي متكامل مخصص للموضوع المكتوب |

## ⚙️ المتغيرات البيئية المطلوبة (`.env` أو إعدادات Render)

```env
# هوية الأستوديو
ARCHITECT_NAME=MK ARCHVIZ
ARCHITECT_HANDLE=@MK.ARCHVIZ

# إعدادات بوت تيليغرام
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_CHAT_ID=your_telegram_chat_id_here

# محرك الذكاء الاصطناعي الرؤيوي الفائق (XKiro AI)
XKIRO_API_KEY=your_xkiro_api_key_here
XKIRO_BASE_URL=https://api.xkiro.com/v1
XKIRO_MODEL=qwen/qwen3.8-omni-flash:free

# محرك صور الخلفيات المعمارية (CometAPI)
IMAGE_API_KEY=your_image_api_key_here
IMAGE_BASE_URL=https://api.cometapi.com/v1
IMAGE_MODEL=gpt-image-2.5-flare

# المفتاح الاحتياطي من Google AI Studio
GEMINI_API_KEY=your_gemini_api_key_here
```

## 🚀 التشغيل السحابي على Render (Cloud 24/7)

1. تأكد من رفع آخر التحديثات لمستودع GitHub (`porchdani428-hub/arch-bot2`).
2. في لوحة تحكم Render:
   - توجه إلى خدمة الويب **arch-bot2**.
   - ادخل إلى تبويب **Environment** وتأكد من إضافة المتغيرات أعلاه (خاصة `XKIRO_API_KEY` و `IMAGE_API_KEY` و `TELEGRAM_BOT_TOKEN`).
   - اضغط على **Manual Deploy** ➔ **Deploy latest commit**.
3. سيعمل البوت تلقائياً في السحابة ويبقى حياً 24/7!
